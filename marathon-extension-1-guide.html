무엇을 해주나요

검색칸을 대신 채웁니다

종목, 요일, 접수여부, 지역, 년도, 월, 검색대상, 검색어 8가지를 미리 골라두고 한 번에 채웁니다. 필요한 항목만 골라도 됩니다.

탭마다 따로 기억합니다

새로고침하거나 메뉴를 옮겨 다녀도 그 탭에서 정한 조건이 다시 채워집니다. 탭을 닫으면 사라집니다.

검색은 직접 누릅니다

값만 채우고 사이트에 검색을 보내지는 않습니다. 사이트 운영에 부담을 주지 않도록 검색 버튼은 항상 사용자가 누릅니다.

설치하기

스토어에 올라간 확장 프로그램이 아니라서 개발자 모드로 설치합니다. 처음 한 번만 하면 되고, 3분 정도 걸립니다. 사용하는 브라우저를 고르세요.

  1. 설치 폴더를 준비합니다

    전달받은 파일이 zip이면 먼저 압축을 풉니다. 안에 있는 extension 폴더가 설치할 폴더입니다. 이 폴더는 설치한 뒤에도 지우거나 옮기지 마세요. 폴더가 없어지면 확장 프로그램도 동작하지 않습니다.

  2. 확장 프로그램 관리 화면을 엽니다

    주소창에 chrome://extensions 를 입력하고 Enter를 누릅니다. 오른쪽 위 ⋮ 메뉴에서 확장 프로그램 → 확장 프로그램 관리로 들어가도 됩니다.

  3. 개발자 모드를 켜고 폴더를 불러옵니다

    오른쪽 위 개발자 모드 스위치를 켭니다(①). 그러면 왼쪽 위에 버튼들이 나타나는데, 압축해제된 확장 프로그램 로드를 누르고(②) 1단계의 extension 폴더를 선택합니다.

  4. 툴바에 고정합니다

    주소창 오른쪽의 퍼즐 모양 확장 프로그램 아이콘을 누르고, 목록에서 마라톤 검색 옵션 도우미 옆의 압정 아이콘을 누릅니다. 이제 툴바에 마 아이콘이 항상 보입니다.

검색 조건 채우기

  1. 대회일정 페이지를 엽니다

    marathon.pe.kr 대회일정을 열고 툴바의 마 아이콘을 누릅니다. roadrun.co.kr 대회일정 목록을 바로 연 경우에도 똑같이 동작합니다.

  2. 원하는 조건만 고릅니다

    모든 항목은 선택 사항입니다. 고르지 않은 항목은 선택 안 함으로 채워집니다. 년도는 올해 기준으로 10년 전부터 내년까지 고를 수 있습니다.

  3. 반영을 누릅니다

    사이트의 검색칸이 고른 조건으로 바뀝니다. 아직 검색된 상태는 아닙니다.

  4. 사이트의 검색 버튼을 직접 누릅니다

조건이 유지되는 방식

반영한 조건은 그 탭에만 기억됩니다. 상황별로 이렇게 동작합니다.

이럴 때검색칸은 이렇게 됩니다
새로고침, 왼쪽 메뉴 이동, 전체일정 클릭사이트가 검색칸을 비우면 반영해 둔 조건을 다시 채웁니다.
사이트에서 검색칸을 직접 바꿔 검색결과 화면에는 직접 바꾼 조건이 그대로 보입니다. 확장 프로그램에 반영해 둔 조건은 바뀌지 않으므로, 다음에 새로고침하면 반영해 둔 조건이 다시 채워집니다.
새 탭에서 사이트 열기빈 상태로 시작합니다. 탭마다 다른 조건을 쓸 수 있습니다.
탭 또는 브라우저 닫기그 탭의 조건이 지워집니다. 최근 검색 목록은 남아 있습니다.

최근 검색과 초기화

최근 검색에는 반영을 누른 조건이 최근 것부터 10개까지 남습니다. 브라우저를 껐다 켜도 유지됩니다. 같은 조건을 다시 반영하면 새로 쌓이지 않고 맨 위로 올라갑니다. 사이트에서 직접 한 검색은 기록되지 않습니다.

목록의 항목을 누르면 팝업의 선택칸만 그 조건으로 바뀝니다. 사이트에 적용하려면 이어서 반영을 누르세요.

초기화를 누르면 팝업의 선택칸과 이 탭에 기억된 조건이 지워집니다. 사이트 검색칸과 최근 검색 목록은 그대로 둡니다.

문제가 생겼을 때

반영 버튼이 회색이라 눌리지 않아요
지금 탭이 대회일정 페이지가 아닌 경우입니다. 대회일정 페이지인데도 그렇다면 그 탭을 새로고침하세요. 설치나 업데이트 전에 열어둔 탭은 새로고침해야 인식됩니다.
"사이트에 없는 값이라 채우지 못했습니다"라고 나와요
고른 값이 사이트의 선택 목록에 없을 때 나옵니다. 예를 들어 사이트가 아직 지원하지 않는 년도를 고른 경우입니다. 그 항목은 비워두고 나머지 항목만 채웁니다.
브라우저를 켤 때 개발자 모드 확장 프로그램 경고가 떠요
스토어를 거치지 않고 설치한 확장 프로그램이 있으면 Chrome과 Edge가 보여주는 안내입니다. 이 확장 프로그램을 계속 쓰려면 사용 중지하지 말고 창을 닫으면 됩니다.
새 버전을 받았어요
기존 extension 폴더의 내용을 새 파일로 바꾼 뒤, 확장 프로그램 화면의 카드에서 새로고침 아이콘(Chrome) 또는 다시 로드(Edge)를 누릅니다. 그다음 열려 있던 사이트 탭도 새로고침하세요.
내 정보가 어딘가로 전송되나요?
아니요. 검색 조건은 이 브라우저 안에만 저장됩니다. 사용하는 권한은 저장 공간 하나뿐이고, 대회일정 목록 페이지에서만 동작합니다. 사이트나 다른 서버로 요청을 보내지 않습니다.
